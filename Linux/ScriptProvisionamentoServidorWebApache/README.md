### Infraestrutura como Código: Script de Provisionamento de um Servidor WEB (Apache)

Projeto desenvolvido na **Formação Linux Fundamentals** que teve como objetivo criar um script para criar um servido web com Apache.

O scrip realiza as seguintes operações:

- Atualiza o servidor
- Instala o Apache
- Instala o Unzip
- Baixa do GitHub, em formato zip, o repositório que com o arquivo a ser utilizado no servidor web Apache
- Descompacta o arquivo do repositório que foi baixado
- Copia o arquivo `readme.html` para a pasta do servidor web.
